# Independent ERA5 and COVID setting review — 2026-09-30

Scope: read-only inspection of current preparation/protocol/selection code, manuscript, and recovered ERA5 arrays; no model runs, code edits, job changes or new baselines. The policy and recovery note were treated as intended design/evidence pointers, not proof. Paths below are absolute. Severity refers to claims/result reuse, not necessarily an implementation defect.

## Verdict and task definitions

The rebuilt ERA5 setting is defensible as **retrospective, covariate-assisted, hourly spatial interpolation of an ERA5-Land field**. COVID is defensible as **retrospective weekly spatial nowcasting with simulated one-week reporting delay and previously observed query jurisdictions**. Neither is future forecasting. They are useful different online-inference problems; neither alone demonstrates general nonstationary-task adaptation or the necessity of long-term HiPPO memory. Existing manuscript descriptions and old numerical results must not be silently carried over.

| Property | Rebuilt ERA5 | Rebuilt COVID | PEMS comparison boundary |
|---|---|---|---|
| Initial period | 186 hours, 800 visible locations | 52 weeks, all 52 jurisdictions | 2,016 sample times, 260 visible sensors |
| Online query | Same-hour 200 spatially held-out locations after observing 800 current targets | Same-week 10 jurisdictions after observing 42 current targets | Same-sample 65 sensors after observing 260 current targets |
| Query-label release | Never | Previous week's query labels arrive before current query | Previous sample's query labels arrive |
| Initial spatial fit/validation | 720/80; final 200 never initial labels | 38/4; all 52 become legal for posterior initialization | Fit subset of visible sensors; initial hidden labels excluded |
| Mean information | Six current weather fields at all sites + 10-hour lags/differences; no target lag | Own target lags 1–4, rolling level/difference, previous fit-site mean, time and coordinates | Different traffic feature family, needs separate reviewer verification |
| Replication | Five masks, same physical period | Five masks, same physical period | Three masks, same physical period |

ERA5 and PEMS source-time issues must not be equated: ERA5 has directly matched missing source rows at six sites and a verified uniform **UTC** replacement grid. The reported PEMS naive-clock DST jump requires timezone evidence before calling it missing physical observations. Different label-release contracts across domains are intentional problem-family differences; unequal contracts among methods within one domain would be unfair.

## Findings

### High: old and rebuilt ERA5 are different prediction experiments

The manuscript still specifies 171 blocks across Tasks 2–10, with blockwise assimilation before prediction (`/data/nk523/projects/hipposvgp-overleaf-6aba8fcfb715ddc40d02c0d2/appendix.tex:297`, `:299`). The rebuilt source explicitly makes 1,674 one-hour blocks and records the change from ten-hour batches (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_era5.py:73`, `:76`). In a multi-hour block, using the entire visible block before evaluating all its rows permits later-within-block observations for earlier queries. That can be a legitimate block-end reconstruction task, but does not establish hourly causal predictions. The new construction removes this issue.

Additionally six legacy sites omit one distinct source hour each, so all subsequent rows there denote hour t+1 at row t. Evidence lists sites 35/83/117/296/434/990 and omissions 577/293/506/507/291/1328 in `/data/nk523/projects/hipposvgp-fair-comparison/outputs/era5-recovered-fair-20260930/source-verification.json:29`. The archived alignment report gives maximum direct target disagreement 4.45336 K, versus 6.86012e-6 K after restoring the row mapping (`:27`). This is a time-alignment correction, not merely benign re-encoding. If an affected site is visible, it previously supplies a one-hour-ahead value; if hidden, its evaluation target has the wrong physical time. All five masks have affected visible sites; affected hidden sites in seeds 0–4 are respectively [117,296], [990], [], [296], [83,990].

**Reuse:** old ERA5 predictions, rankings, timing per block, and the old table cannot serve as the rebuilt hourly comparison, including unaffected hidden sites whose posterior used affected visible observations. Retain as explicitly separate historical block-reconstruction evidence only. The all-site alignment report proves target consistency over the full period and weather overlap over 372 hours, not independent validation of every recovered weather value across all 1,860 hours.

### High for operational claims, not a breach of the stated retrospective contract: source-time is not publication-time

ERA5 preparation includes concurrent t2m/skt/u10/v10/sp/tp at every query site (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_era5.py:10`, `:72`; `/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/era5_features.py:7`). Those are plausible legal exogenous inputs for reconstructing one component of a completed reanalysis field. They are not established operational measurements available at the target UTC hour. [ECMWF describes ERA5-Land](https://www.ecmwf.int/en/forecasts/datasets/era5-land-hourly-data-1950-present) as an offline land replay with indirect observational influence through atmospheric forcing. Shared physical source and current temperature features create a strong target proxy; this is not direct target leakage, and code explicitly excludes d2m from the weather inputs. Claim conditional field reconstruction, not weather forecasting or reconstruction from sparse weather stations alone. Locations are grid cells in a UK-region bounding box, not 1,000 independent instrument stations; exact geographic membership is not audited.

COVID uses one downloaded historical snapshot, indexed only by week-ending date, without historical release-vintage timestamps (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:62`, `:82`). Its one-week hidden-label delay is imposed by the protocol (`/data/nk523/projects/hipposvgp-fair-comparison/baselines/covid_long_setting_b/protocol.py:188`), not derived from observed reporting delays. [CDC distinguishes final weekly publication from preliminary data](https://data.cdc.gov/Public-Health-Surveillance/Weekly-Hospital-Respiratory-Data-HRD-Metrics-by-Ju/mpgq-jmmr/data?pane=feed). This snapshot does not prove historical as-of availability. Minimal fix is explicit retrospective simulated reporting, with current visible and lagged hidden labels assumed available at the declared decision event. Real-time epidemiological forecasting would require a different vintage-aware task and reruns; that expansion is unnecessary for the present GP inference claim.

### High for spatial-generalization wording: COVID query sites are observed initially and continually revisited

`task1()` returns all initial labels at all 52 sites (`/data/nk523/projects/hipposvgp-fair-comparison/baselines/covid_long_setting_b/protocol.py:168`). Each subsequent step returns prior hidden labels and current visible labels (`:188`, `:198`). Thus no claim of permanently unseen jurisdictions is supported. The paper says 42 observed/10 held out and predicts before labels are revealed, but omits the all-site initialization and exact one-week release in its dataset paragraph (`/data/nk523/projects/hipposvgp-overleaf-6aba8fcfb715ddc40d02c0d2/appendix.tex:315`). Explicitly say “10 temporarily withheld jurisdictions per week, observed in the initial year and with a one-week delayed label thereafter.” ERA5 differs substantively: its hidden targets never enter initial/posterior training.

COVID lag features are direct past-target predictors, legitimately available under this delay: target lags 1–4, their rolling mean and lag1−lag2 difference, and previous fit-site aggregate (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:28`). Their memory is additional to the GP state. Results test the combined mean-plus-GP construction, not a claim that every usable historical signal is compressed exclusively by HiPPO. No feature removal or added ablation is required; disclose this information set and qualify the inference claim.

### Moderate: preprocessing is fit-only, but COVID chronological selection uses the eventual query locations within Task 1

Good: COVID target normalization uses first 52 weeks at the 38 fit sites; feature fit also uses those sites; all other sites' initial target lags are imputed, preventing hidden/validation histories leaking into the initial spatial fit (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:35`, `:46`, `:94`). ERA5 target and weather statistics use only 186 initial hours at 720 fitting sites (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_era5.py:71`; `/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/era5_features.py:9`). Ridge coefficient fitting selects only those sites and fixed penalty 1e-3 (`/data/nk523/projects/hipposvgp-fair-comparison/baselines/covid_long_setting_b/development.py:129`). Known coordinates at query sites are used for coordinate scaling; this is covariate transduction, not target leakage.

However COVID `build_fold` retains the formal `test_indices`, exposes all sites during its first 40 weeks, and evaluates its remaining 12 Task-1 weeks at those same final-query locations (`/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/online_validation.py:15`, `:31`, `:38`). This is actually invoked by OSGPR/OHSVGP campaign selection (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/run_osgpr_final_campaign.py:27`, `:100`; `/data/nk523/projects/hipposvgp-fair-comparison/scripts/run_ohsvgp_final_campaign.py:26`, `:34`). It does **not** use the 143-week formal test stream, and initial all-site observation makes it causally legal. But it contradicts a blanket assertion that final spatial locations never participate in tuning. ERA5's fold instead subsets to original 800 visible sites and scores the internal 80 (`/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/online_validation.py:112`).

Minimal defensible resolution: explicitly permit COVID historical observations at eventual query jurisdictions for chronological tuning for every method; distinguish this from the disjoint 38/4 initial spatial-validation split. If strict outer spatial exclusion is intended instead, rebuild that fold over visible sites and rerun affected selection/finals. Do not label the existing fold future-test leakage without distinguishing time and space.

COVID feature design also changes at initialization: nonfit-site historical lags are imputed in initial calibration but actual lag values become available at stream start (`prepare_fair_covid.py:35`). This is legal but an artificial feature-distribution transition, not epidemiological concept drift. State it; model calibration relevance across that transition is a limitation, not proof of failure.

### Moderate: “Task” means partition/update, not independently changing data-generating tasks

ERA5 data checked here cover 2020-01-01 00:00 UTC through 2020-03-18 11:00 UTC, only 77.5 days. Initial 186 hours are 7.75 days, followed by 69.75 days. Task boundaries are storage/batch partitions, not independently defined environmental regimes. COVID uses 195 consecutive weeks from 2020-08-08 through 2024-04-27 (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:66`); first-year calibration followed by later epidemic waves can change distributions, but weekly boundaries do not themselves prove a new regime every week. The manuscript's “COVID-19 introduces weekly public-health regime changes” overstates demonstrated structure (`/data/nk523/projects/hipposvgp-overleaf-6aba8fcfb715ddc40d02c0d2/main.tex:509`). Use “weekly observations spanning changing epidemic conditions.”

ERA5 time features have periods 185 and 92.5 hours because phase is 2π times hour/185 (`/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/era5_features.py:11`). They are generic basis features, not daily/annual seasonality. Chronological ERA5 validation changes the scale to 129 hours (`/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/online_validation.py:117`), so its mean basis differs from the final basis. This is not future leakage, but should not be explained as a physically fixed seasonal encoding. Keep unchanged for reuse if described as generic normalized-time features. Changing to physical periods would require fresh selection/finals.

The 133 ERA5 features include exact linear redundancy: each current-minus-lag column is a linear combination of current and lag columns. Ridge regularization makes fitting defined, and joint Bayesian priors need not be invariant to redundant parameterization. Do not infer 133 independent exogenous signals or dismiss mean-design differences among domains. No extra comparison is requested.

### Moderate: five masks do not mean five independent streams or five pure training replicates

COVID seeds 5–9 generate spatial masks, inner masks use seed+1729 (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:91`; `/data/nk523/projects/hipposvgp-fair-comparison/scripts/iclr_era5_full_benchmark_protocol.py:80`). ERA5 reuses five archived masks on one time series (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_era5.py:67`). Proposal training seed is 0 (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/run_era5_kronhippo_campaign.py:15`); OSGPR records training_seed=split seed (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/run_osgpr_final_campaign.py:40`). Within-domain methods should share masks and target scales, but training randomness need not be numerically identical across distinct algorithms. Record the distinction. Across-mask SD mixes mask and some methods' optimization variability and is descriptive sensitivity on the same dependent field, not uncertainty over independent future datasets. Neither hours×sites nor overlapping masks are IID scientific replications. Report paired per-mask differences and avoid treating all prediction rows as independent significance samples. This needs reporting fixes, not automatic additional runs.

### High: COVID historical snapshot replacement prevents blind reuse of earlier scores

Preparation states historical_snapshot_bitwise_identical=False and only requires per-location correlation >0.98 against the old development archive (`/data/nk523/projects/hipposvgp-fair-comparison/scripts/prepare_fair_covid.py:78`, `:85`). Correlation verifies broad alignment, not exact equality. New protocol also specifies its own legal fit-only scaling, features and beta. Earlier scores cannot be presumed comparable based on jurisdiction count and date extent; require exact protocol/source/transform identity before reuse. Completed new-campaign outputs may remain usable for the retrospective task once the independent method/selection audit admits them. This review did not inspect each remote job's immutable release or determine completion/admission.

## Minimal defensible paper/campaign resolution

1. Keep the five planned methods and existing three problem families. Define the decision event and information set in the comparison table above; require it to match across all methods within each dataset. Current-only query means, initial posterior targets, hidden-release events and selected-target normalization must agree. Different inference update mechanisms are legitimate method differences, provided documented and separately validated.
2. Replace old ERA5 numerical evidence for the corrected comparison; distinguish archived batch results and mechanism claims from current hourly results. State actual UTC extent, six corrected site gaps, no hidden release, and retrospective reanalysis covariates.
3. Preserve COVID all-site initialization and one-week artificial delay as the authorized task. State initial versus online feature availability, source snapshot, exact dates, log1p(per-100k) metric scale, and the allowed Task-1 historical tuning scope.
4. Replace “weekly regime changes,” blanket unseen-site generalization and operational forecasting interpretations with the narrower supported online spatial regression claims. The experiments support performance and computational behavior of bounded-state inference under these contracts; they do not independently isolate why HiPPO works. No new baseline or ablation is needed to make this statement defensible.
5. Report per-mask results with separate training-seed metadata; preserve new completed predictions only where exact source, protocol, feature, selection, and immutable implementation provenance passes the other reviewers' checks. Rewording retrospective scope alone does not require reruns. Changing current weather availability, lag availability, release timing, final location exclusion during historical tuning, or physical seasonal features does.
