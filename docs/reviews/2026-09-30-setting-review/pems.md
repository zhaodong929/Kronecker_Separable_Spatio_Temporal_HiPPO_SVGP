## Executive finding

PEMS is a legitimate long-stream online spatial nowcasting test, but the current delayed-label version does **not** instantiate the paper's single-spatial-geometry Sylvester theorem. The granularity is 50,100 five-minute updates to one stream, not 50,100 independent tasks. Making updates coarser would lower cost but does not fix the geometry mismatch; retaining each five-minute score while batching computation is a different issue from exposing future labels. A fair five-method comparison can retain this dataset either by retaining and clearly describing the multi-geometry extension, or by switching all methods to fixed visible sensors whose hidden labels are never assimilated. The latter most directly tests the stated fixed-geometry claim.

## Critical: solver claim and experiment are different mathematical cases

Manuscript `/data/nk523/projects/hipposvgp-overleaf-6aba8fcfb715ddc40d02c0d2/main.tex:354` fixes C and G=CᵀC; proposition at line360 assumes unchanged spatial observations, and line372 gives a single likelihood Kronecker term. Delayed assimilation alternates current 260-visible geometry and prior-time 65-hidden geometry. Generally G_visible and G_hidden differ, leaving a sum of likelihood Kronecker terms. Enlarging temporal blocks does not change this fact.

The new implementation explicitly recognizes it: `/data/nk523/projects/hipposvgp-fair-comparison/scripts/run_iclr_era5_routeb_strict_online.py:505` selects `TorchMultiGeometryHiPPOSVGP` when delay is enabled; line993 reports `sum_kronecker_sylvester_preconditioned_cg` and line994 sets `fixed_geometry_complexity_claim_applies` false. `/data/nk523/projects/hipposvgp-fair-comparison/stvgp_kronecker/joint_ssgp_kron/multi_geometry.py:3` describes storing a sum and explicitly disclaims the single-Sylvester guarantee. Campaign qualification says the same at `/data/nk523/projects/hipposvgp-fair-comparison/slurm/fair_three_domain/pems_tracked.sbatch:30` and pending admission at line41.

Thus this is a critical **claim-to-evidence mismatch if promoted unchanged into the present paper**, not evidence that the new solver is numerically wrong. Bounded memory can still hold with a fixed finite number of geometries, but the advertised exact single-Sylvester recovery and its complexity are not established by these runs. Manuscript conclusion lines554–558 itself says richer observation patterns need more general states.

## Major: tuning representativeness and comparison unit

The fold is a reasonable steady-state delayed-update tuning proxy, not an exact replica of first-arrival cold-start conditions. One Saturday is weak evidence of optimizer-budget robustness over six months and weekday congestion.

No new baselines or ablations are needed to improve this: use predeclared chronological validation tails covering weekdays and weekend, ideally lengthen common initialization enough for multiple weekly cycles if changing the protocol; keep all65 final sensors and final stream out of selection. Explicitly report which method receives which budget/capacity search and convergence gate. Proposed tracked worker fixes Ms32/Mt128/RFF256 with up to250 iterations and patience8 (`/data/nk523/projects/hipposvgp-fair-comparison/slurm/fair_three_domain/pems_tracked_worker.sh:11`–15). Remote selection records show independent ST-SVGP and MGPVAE optimization (not merely copied proposal parameters), but complete source-locked configurations across all15 finals have not been certified here.

There are 3,256,500 scalar predictions per split (50100×65); these are correlated in time and space. Three spatial seeds share the same physical stream and overlapping sensor sets; report paired split variability, not standard errors assuming millions of independent samples. Effective sample size cannot be inferred just from cadence; temporal correlation or block-based uncertainty estimates are required. Daily/weekly paired summaries can be computed from existing predictions without adding experiments.

## Horizontal interpretation and redesign choices

PEMS differs from COVID in both time scale and initialization: five-minute steps vs weekly; final hidden sensors absent initially vs COVID all52 initially observed; both release hidden labels one step later. PEMS differs from ERA5 because ERA5 final hidden labels never arrive. Thus “one-step delay” is neither the same physical delay nor the same spatial generalization problem across datasets. PEMS current-speed road context is target-derived; ERA5's weather covariates are non-target channels. Matching five method names alone does not make these information regimes equivalent.

1. **Keep current nowcasting/reveal protocol.** Retain all five methods, fix the shared time contract, describe delayed observation geometries and iterative sum-Kronecker extension, and scope single-Sylvester claims to settings actually satisfying it. Report full update, delayed assimilation, feature and solver costs. This preserves delayed online prediction but requires manuscript methodology changes.
2. **Prefer fixed-visible/no-reveal if the fixed-geometry theorem is the central claim.** Keep260 visible throughout; never assimilate65 hidden labels. All five methods predict the same hidden65 from current visible and their visible histories. This matches spatial interpolation and fixed observation geometry, requires re-running the PEMS comparison, and changes the scientific question deliberately. Common mean features remain legal. Apply a similarly explicit decision to COVID rather than silently claiming all settings match.
3. **Choose coarser native measurement cadence only for a declared application objective.** Common 15/30/60-minute subsampling or aggregation reduces all methods' updates. State whether target is instantaneous or interval-average speed and use identical arrival times. Scoring every5minutes while updating once/hour changes what current labels can be used. Merely calling 12 five-minute steps one “Task” neither lowers required information updates nor repairs geometry. Choose one final protocol before using final scores to make the choice; this need not become an ablation suite.
