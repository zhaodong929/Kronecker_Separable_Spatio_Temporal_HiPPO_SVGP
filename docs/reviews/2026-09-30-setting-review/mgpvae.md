## Scientific and causal implementation checks

**Official model and whitening.** `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/official.py:10` verifies the upstream commit and tracked model-tree cleanliness. It uses the upstream `STMarkovGaussianProcessVAEExternal`, spatiotemporal Matérn-3/2 kernel, scalar encoder, nonlinear decoder and Gaussian observation noise. Upstream `/data/nk523/projects/mgpvae-audit-20260929/mgpvae/kernels.py:1024` explicitly has identity spatial measurement (`I ⊗ [1,0]`); spatial correlation enters through the downstream Cholesky map. This is a whitened variational latent representation. Encoding a site's observation into its corresponding whitened pseudo-site is inherited from the pinned official inference family, not exact conditioning of physical correlated observations; do not advertise the adaptation as exact nonlinear posterior inference. Dependence on spatial Cholesky ordering is also inherited. The construction deliberately appends initially unobserved sites after training sites to preserve the original conditional before any delayed release.

**Covariance correction.** Upstream `/data/nk523/projects/mgpvae-audit-20260929/mgpvae/model.py:829` mixes means and left-multiplies covariance by `L` only. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/spatial_moments.py:9` uses `L P L.T`, leaves the whitened KL calculation unchanged, and obtains physical-space reconstruction marginals. This is the appropriate covariance pushforward; it changes the numerical training objective relative to the buggy pinned implementation while preserving the intended model. Independent dense-product and KL/decomposition tests are present in `/data/nk523/projects/hipposvgp-fair-comparison/tests/test_mgpvae_spatial_moments.py:6`. Pinned temporal parameter accessor naming is unusual and remains unchanged; report effective parameters rather than inferring semantics from internal variable names.

**Selected-site update and delayed labels.** `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/selected.py:18` guards the exact identity measurement before simplifying the dense selected-row update to scalar innovations. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/partial.py:100` retains the state before the previous time, recomputes that previous update jointly with newly released hidden observations, then advances to the current visible observations. This applies the previous visible likelihood once in the reconstructed posterior, rather than sequentially adding it twice. The previous-step-only restriction is explicit. Frozen parameters make the saved-state rewind meaningful.

The lawful prefix reference excludes unreleased observations before encoding (`partial.py:63`). Tests include actual hidden/future target mutation, dense Gaussian conditioning, every-prefix comparison under irregular times, duplicate rejection, and the bounded-delay implementation (`tests/test_mgpvae_partial.py:42`; `:82`). `tests/test_mgpvae_selected.py:15` compares the fast and dense delayed paths; `:32` checks appended-site conditional equivalence. These are real numerical evidence, not only declarations. The production `current_hidden_labels_read=0` at `run_mgpvae_causal.py:269` is a literal metadata value, not an instrumented read counter. It must not be described as independent proof of no leakage. `evaluation_targets()` loads truth before the loop (`:216`), but its inspected usage is scoring after prediction (`:239`); data residency alone is not a leak. No adverse prediction dependence on those stored evaluation values was found.

**Initial prediction and compact training.** `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/initial.py:31` calls official RTS and temporal interpolation on independent 2×2 blocks, retaining the official `1e-8` temporal bridge regularization even at observed times. Simply using raw smoother marginals would not reproduce official prediction exactly; the implementation correctly addresses this. `/data/nk523/projects/hipposvgp-fair-comparison/tests/test_mgpvae_initial_marginals.py:7` covers two latent capacities, two time scales, and changed parameter values. These synthetic checks establish the intended algebra, not the failing GPU geometry.

Compact reconstruction uses `diag(L P L.T)=(L**2)diag(P)` under the guarded block-independent posterior (`spatial_moments.py:34`), with dense loss/all-gradient checks in `tests/test_mgpvae_compact_energy.py:8`. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/sitewise_filter.py:4` uses official scalar Kalman filters for each independent whitened site, rejecting masks/parallel mode. The saved full-geometry ERA5 GPU dense/sitewise objective checks passed both latent sizes with loss errors at most `5.83e-11`, gradient errors at most `2.13e-11` (`outputs/mgpvae-sitewise-era5-full-initial-gpu-qualification.json`). These are useful training-equivalence evidence; they cannot override an actual failed prediction test.

**Selection/refit and information.** Initial validation uses all legal Task-1 times at fitting sites, smoothing only that initial rectangle, and scores separate Task-1 spatial validation sites. This is permitted offline initialization, not future leakage into the online stream. The selected iteration and capacity are then refitted from a fresh seeded initialization on all initially released sites (`run_mgpvae_causal.py:196`). COVID starts with all 52 sites; PEMS/ERA5 initially refit 260/800 sites and append the withheld sites. COVID/PEMS release one-step-old hidden labels; ERA5 never releases hidden labels. The runner consumes the protocol's explicit delayed record and does not invent a common delay rule across domains (`:221`). Frozen selection checks architecture, split, protocol hash and official commit (`:180`); broader configuration provenance belongs to the campaign record.

Temporal inputs remain meaningful and lawful: absolute time is shifted/scaled by the Task-1 span (`run_mgpvae_causal.py:73`), its increments drive the Matérn state transitions, and the scalar encoder receives residual targets. Calendar/weather/lag covariates enter this adaptation through the common mean, not as additional nonlinear decoder inputs. This differs from other kernels' temporal features or the proposal's joint mean learning; describe model differences rather than silently asserting identical temporal representations. No task instruction requires every method to have the same temporal kernel.

**Predictive distribution and metrics.** `/data/nk523/projects/hipposvgp-fair-comparison/baselines/mgpvae/filtering.py:66` samples independent latent channels from the marginal Gaussian, applies the decoder, and retains Gaussian decoder noise. Per-point RMSE/NLPD/CRPS need these marginals, not cross-site sample correlations. `/data/nk523/projects/hipposvgp-fair-comparison/benchmarks/three_domain/metrics.py:6` uses log-sum-exp mixture NLPD and the correct Gaussian-mixture CRPS formula; `:27` uses exact finite-mixture CDF/PIT central coverage. It does not evaluate ELBO as NLPD or Gaussianize a nonlinear predictive mixture. The JAX score path implements the same formulas and enforces float64. Pooled ECE is computed from pooled coverage rather than averaging absolute per-time ECE (`run_mgpvae_causal.py:263`).

Saved latent moments, refit decoder checkpoint, seeds, noise and sample count make predictions reconstructible. The existing independent COVID seed-5 check reconstructs decoder moments and mixture scores at steps 1, 72, 143 (`outputs/mgpvae-completed-reference-check-20260930/seed5/independent-decoder-reconstruction.json`). This is strong targeted evidence for scoring, not proof of all training or protocol behavior. Inference timings explicitly exclude score evaluation (`run_mgpvae_causal.py:237` and `:241`); compare other methods using the same timing boundary and report initial fitting/refitting separately.
