# Independent ST-SVGP review — 2026-09-30

Scope: implementation snapshot `/data/nk523/projects/hipposvgp-fair-comparison`, commit `4f881c7ee9de5ec203b1bd79589627c1f1f3417b`; actual completed COVID, PEMS and ERA5 artifacts on corgi; pinned Aalto repository and installed BayesNewton 1.1. Read-only source/artifact inspection and bounded NumPy comparisons only. No GPU computation, source edits, job changes, or external messages. This report is the only new artifact for this task.

**Conclusion:** the implementation is a defensible Gaussian, frozen-hyperparameter causal adaptation of ST-SVGP, with a bounded-state continuation that preserves the same variational posterior as official lawful-prefix inference. It is not an unrelated state-space approximation merely carrying the ST-SVGP name. I found no demonstrated scientific correctness failure in the completed runs. The principal corrections needed are timing/accounting descriptions, distinguishing actual parity scope from universal claims, and disclosing unequal model-learning schedules across methods. Five COVID, one PEMS and one ERA5 complete runs are available; this is not the full 5/3/5 paired benchmark.

**Medium — the field named `initial_filter_and_prefix_seconds` also includes online logging and checkpoint overhead.** `/data/nk523/projects/hipposvgp-fair-comparison/baselines/covid_long_setting_b/adapters/run_st_svgp.py:435` starts each update timer; `:448` stops it after synchronized NumPy prediction. `emit` at `:450` and growing compressed checkpoint saves at `:452` are outside these individual timers. `:622` measures the whole continuation; `:696` defines “initial filtering” as whole continuation minus the sum of individual update times. This remainder therefore contains initial construction/filtering **plus** online logging, checkpoint serialization, list/stack work and loop overhead. It is not a separately measured initial-filter time.

The actual PEMS seed-1 final `/vol/bitbucket/nk523/hipposvgp-fair-20260929/results/fair-three-domain-wandb-20260929/pems/st_svgp/seed1/job-294461/result.json` reports 50,100 updates, **242.5654 s** update-and-prediction time, **352.3855 s** whole continuation, and **109.8201 s** in that remainder; initial model refit is an additional **1326.9218 s**. It excludes final scoring, periodic checkpoint writing, tracking emits and the initial filter. It includes first-use compilation in the timed online path. Approximately 101 checkpoint writes occur over this PEMS stream (every 500 steps plus the last step), repeatedly serializing growing prediction arrays. **Interpretation limitation — frozen parameters and mean are different learning schedules, not automatically unfair information access.** ST-SVGP learns kernel, noise and inducing locations from legal initial data; it then freezes them and updates only the Gaussian variational state. OSGPR/OHSVGP optimize some parameters online; the proposal also jointly updates its Bayesian mean coefficients and GP state. ST uses the same legal covariates through a fixed common ridge mean. This satisfies equal available information while comparing different models/learning schedules. It cannot isolate the solver's contribution to predictive accuracy. Describe the methods as end-to-end adaptations, specify initial/online costs and optimization budgets, and avoid interpreting all accuracy differences as inference efficiency. No extra ablation is necessary to repair this claim.

## Scientific identity and posterior audit

**This is the official full spatial ST-SVGP construction.** The pinned [Aalto repository README](https://raw.githubusercontent.com/AaltoML/spatio-temporal-GPs/c5b929e1fc07b14ff9671dd1d66b3b8041e2a2ce/README.md) identifies BayesNewton as its implementation; [requirements.txt](https://raw.githubusercontent.com/AaltoML/spatio-temporal-GPs/c5b929e1fc07b14ff9671dd1d66b3b8041e2a2ce/requirements.txt) pins BayesNewton 1.1. Its [air-quality model](https://raw.githubusercontent.com/AaltoML/spatio-temporal-GPs/c5b929e1fc07b14ff9671dd1d66b3b8041e2a2ce/experiments/air_quality/models/m_bayes_newt.py) uses Matérn-3/2 temporal and product-spatial kernels, `SpatioTemporalKernel(sparse=True, conditional='Full')`, Gaussian likelihood and `MarkovVariationalGP` when mean field is disabled. Local `/data/nk523/projects/hipposvgp-fair-comparison/baselines/covid_long_setting_b/adapters/run_st_svgp.py:136` instantiates those same components with task-appropriate initial scales and inducing count. It does not substitute `MarkovVariationalMeanFieldGP`. The pinned package metadata on corgi confirms version 1.1. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/bayesnewton_compat.py:6` supplies removed JAX scatter/type APIs and enables float64; it does not alter the probabilistic equations.

**Conjugate site collapse is the ST variational posterior, not a DTC/FITC replacement.** Correlated latent inducing states are retained in a full covariance. In the actual installed source `/vol/bitbucket/nk523/hipposvgp-fair-20260929/env-jax-gpu/lib/python3.11/site-packages/bayesnewton/basemodels.py:621`, physical-site natural parameters are projected as `B.T nat1` and `B.T nat2 B`, then inverted after a `1e-12 I` precision regularizer. For Gaussian likelihood these become `B.T y/noise` and `B.T B/noise`. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/st_svgp_filter.py:39` computes these exact pseudo-sites and uses the official measurement model. The fallback data-space update is algebraically equivalent absent the small site regularizer; the production default retains the regularizer.

Spatial conditional residual covariance `C` belongs in `q(f)=N(Bm, BPB.T+C)` and in the variational expected likelihood. It does **not** belong in the observation noise used for this conjugate variational site update. Adding `C` there would change the approximation. The filter correctly adds `diag(C)` and observation noise at prediction (`st_svgp_filter.py:106`). It caches `B,C`, stationary covariance and measurement because coordinates and hyperparameters are frozen. This would be invalid under online kernel optimization, but the actual adapter does not perform such optimization.

**One unit natural update is sufficient here.** Installed BayesNewton `/vol/bitbucket/nk523/hipposvgp-fair-20260929/env-jax-gpu/lib/python3.11/site-packages/bayesnewton/inference.py:168` implements natural-gradient VI. Gaussian expected-likelihood derivatives give fixed conjugate sites, so repeated unit natural updates are not an optimization-budget handicap to this frozen Gaussian posterior. The runner enforces one update, full history and unit natural learning rate for continuation (`run_st_svgp.py:481`). This does not mean hyperparameter optimization converges in one step: initial Adam training remains separately selected and refitted.

**Initialization, selection and refit.** `run_st_svgp.py:191` alternates official inference with Adam hyperparameter optimization. Validation refreshes the posterior after the Adam update (`:216`) before scoring. Checkpoints save kernel/likelihood values and inducing locations (`:223`). Fitting-site validation selects iterations/capacity; the final invocation trains anew for the selected iteration budget on all legally initial sites. An outdated variational posterior after the last hyperparameter update is not carried online: continuation reconstructs the initial Gaussian state using the frozen final kernel/noise and all initial observations (`:419`). This avoids a stale final-posterior issue. The selected mean is still the common fit-site ridge mean and is restored after residual prediction.

K-means initialization uses all known coordinates (`run_st_svgp.py:498`); knowing withheld query geometry is not access to withheld targets. The initial legal label sets differ correctly by domain: 52 COVID sites, 260 PEMS, 800 ERA5. Frozen-state files record seed/capacity and numerical parameters, not a complete posterior; their isolated reader does not hash the protocol (`:307`). The continuation measurement controller hashes the frozen file and campaign provenance must bind it to its source protocol (`scripts/measure_st_svgp_continuation.py:43`). Do not treat the frozen NPZ alone as a complete reproducibility manifest.

**Causality and delayed assimilation.** `st_svgp_filter.py:72` validates chronological advancement, checks previous-time delayed release and duplicate sites, restores the state before that previous time, updates jointly with old visible and newly released hidden observations, then updates the current visible observations. This avoids both double-counting and relabeling historical observations as current. ERA5 has no delayed hidden release. Replay builds its grid from only released batches (`run_st_svgp.py:384`); no future smoothing is performed beyond the lawful prefix. The reference may smooth earlier states internally, but current endpoint predictions use only currently available observations.

Actual mutation tests, rather than just metadata counters, exist at `/data/nk523/projects/hipposvgp-fair-comparison/tests/test_st_svgp_release_boundary.py:7`: both replay and continuation stay invariant to current hidden-label mutation until release, change after release, and ignore future target changes for earlier predictions. `/data/nk523/projects/hipposvgp-fair-comparison/tests/test_st_svgp_stateful.py:7` tests sparse inducing geometry, irregular times, with/without delay, and both site formulations against official replay. The literal `current_hidden_labels_read=0` output field (`run_st_svgp.py:652`) is an assertion of intended behavior, not a runtime read counter.

**Endpoint bridge is preserved.** Installed BayesNewton `/vol/bitbucket/nk523/hipposvgp-fair-20260929/env-jax-gpu/lib/python3.11/site-packages/bayesnewton/utils.py:184` computes temporal interpolation, including `1e-8` jitter at `:210`. Consequently official prediction at an observed endpoint is not bitwise identical to simply projecting the raw filtered state. `/data/nk523/projects/hipposvgp-fair-comparison/baselines/st_svgp_filter.py:60` reconstructs the two adjacent smoothed states with official RTS and the same temporal conditional, then leaves the unmodified filtered state for subsequent updates. Only the previous/current pair is needed at that endpoint; no whole-history replay is required. The inspected code uses the previous posterior **after** delayed-label assimilation, as required. This is a numerical-convention preservation, not additional access to future observations.

**Uncertainty and memory.** `predict()` returns observation variance, including conditional residual and noise; common metrics then use Gaussian predictive scores, not ELBO. Full-inducing small-data predictions are checked against an independently assembled dense GP in `/data/nk523/projects/hipposvgp-fair-comparison/tests/test_st_svgp_dense.py:3`. The stateful algorithm retains a fixed-size inducing-state mean/covariance and one previous snapshot, so inference-state memory is independent of stream length. The benchmark harness still accumulates predictions, information rows and timing arrays and writes growing output checkpoints (`run_st_svgp.py:433`); total process/output memory should not be described as strictly constant. This distinction applies to other methods' evaluation harnesses too.
