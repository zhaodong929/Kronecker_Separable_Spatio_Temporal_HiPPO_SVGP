1. 总体目标
============================================================

新增实现以下新版方法：

Observation model:
    y_n = Phi_n beta + A_n u_n + eps_n,
    eps_n ~ N(0, sigma^2 I).

Sparse Kronecker projection:
    A_n = T_n \otimes C.

其中：
    T_n = K_fu,n^(t) (K_uu,n^(t))^{-1},
    C   = K_XZ^(s) (K_ZZ^(s))^{-1}.

Changing-basis SSGP-style transfer:
    old inducing variable: u_o
    new inducing variable: u_n

Old posterior and old prior:
    q_{n-1}(u_o) = N(m_o, S_o),
    p(u_o)       = N(0, K_oo).

Old likelihood ratio:
    log q_{n-1}(u_o) / p(u_o)
    = -1/2 u_o^T R_o u_o + u_o^T r_o + const,

where:
    R_o = S_o^{-1} - K_oo^{-1},
    r_o = S_o^{-1} m_o.

But for the scalable implementation, DO NOT recover R_o from a dense S_o.
Instead, maintain old likelihood natural precision as a Kronecker statistic:
    R_o = B_o \otimes G,
    G = C^T C.

Because only the temporal HiPPO basis changes and spatial inducing geometry is fixed:
    L_on = K_on K_nn^{-1}
         = L_on^(t) \otimes I_s,

where:
    L_on^(t) = K_on^(t) (K_nn^(t))^{-1}.

Then:
    Lambda_{o->n}
    = L_on^T R_o L_on
    = [(L_on^(t))^T B_o L_on^(t)] \otimes G.

Define:
    B_{o->n} = (L_on^(t))^T B_o L_on^(t).

The new block likelihood contributes:
    (1/sigma^2) A_n^T A_n
    = (1/sigma^2) (T_n^T T_n) \otimes G.

Therefore:
    B_n = B_{o->n} + (1/sigma^2) T_n^T T_n.

The GP posterior precision keeps the Sylvester-compatible form:
    Lambda_{u,n}
    = (K_nn^(t))^{-1} \otimes K_s^{-1} + B_n \otimes G.

Information vector transfer should also be structured.
Use vectorization convention:
    u = vec(U),
    U has shape (M_s, M_t),
    vec is column-major / Fortran ordering, so
    (T \otimes C) vec(U) = vec(C U T^T).

Maintain the old likelihood information vector in matrix form:
    h_o = vec(H_o),
    H_o has shape (M_s, M_t_old).

Under L_on = L_t \otimes I_s:
    h_{o->n} = L_on^T h_o
             = vec(H_o L_t).

New data information contribution:
    h_new = (1/sigma^2) A_n^T (y_n - Phi_n m_beta)
          = vec( (1/sigma^2) C^T R_n T_n ),

where R_n is the residual matrix with shape (N_s, N_t):
    R_n = reshape(y_n - Phi_n m_beta, (N_s, N_t), order="F").

So update information matrix:
    H_n = H_o L_t + (1/sigma^2) C^T R_n T_n.

The posterior mean M_u solves:
    [(K_t_new^{-1}) \otimes K_s^{-1} + B_n \otimes G] vec(M_u) = vec(H_n).

Use the existing Sylvester solver if available. If no solver exists, implement:
    K_s^{-1} M_u K_t_new^{-1} + G M_u B_n = H_n.

Do not redo the dense-vs-Sylvester validation as a main experiment because it has already been done, but ensure the solver is callable.

3. 必须实现的核心函数
============================================================

In src/joint_ssgp_kron/kron_utils.py implement:

1. kron_mv(T, C, U)
   Purpose:
       Compute (T \otimes C) vec(U) without materializing A.
   Convention:
       U shape = (M_s, M_t)
       result matrix = C @ U @ T.T
       return vec(result, order="F") or matrix depending on argument.

2. kron_t_mv(T, C, R)
   Purpose:
       Compute (T \otimes C)^T vec(R).
   Convention:
       R shape = (N_s, N_t)
       output matrix = C.T @ R @ T
       shape = (M_s, M_t).

3. dense_A_from_factors(T, C)
   Purpose:
       Return np.kron(T, C).
       Used only in tests for small sizes.

4. make_spd_matrix(dim, jitter=1e-4, seed=None)
   Purpose:
       Generate stable SPD matrices for tests.

5. relative_fro_error(A, B)
   Purpose:
       norm(A-B)/max(1,norm(B)).

6. solve_sylvester_precision(Kt_inv, Ks_inv, B, G, H)
   Purpose:
       Solve:
           Ks_inv M Kt_inv + G M B = H.
       Use scipy.linalg.solve_sylvester if directly transformable, or use eigendecomposition/linear solve.
       The function should be robust and tested on small cases.
       This solver is required for model implementation, but do not make Sylvester-vs-dense solve the main new verification because that has already been done.

In src/joint_ssgp_kron/ssgp_transfer.py implement:

1. compute_Lt(K_on_t, K_nn_t, jitter=1e-6)
   Formula:
       L_t = K_on_t @ inv(K_nn_t).
   Use Cholesky solve, never explicit inverse.

2. transfer_temporal_precision(B_old, L_t)
   Formula:
       B_trans = L_t.T @ B_old @ L_t.

3. transfer_information_matrix(H_old, L_t)
   Formula:
       H_trans = H_old @ L_t.
   H_old shape = (M_s, M_t_old).
   L_t shape = (M_t_old, M_t_new).
   H_trans shape = (M_s, M_t_new).

4. update_temporal_likelihood_stat(B_trans, T_n, sigma2)
   Formula:
       B_new = B_trans + (T_n.T @ T_n) / sigma2.

5. update_information_matrix(H_trans, C, residual_matrix, T_n, sigma2)
   Formula:
       H_new = H_trans + (C.T @ residual_matrix @ T_n) / sigma2.

6. projected_prior_transfer_dense(...)
   Implement the projected-prior baseline:
       m_proj = K_no K_oo^{-1} m_old
       S_proj = K_nn + K_no K_oo^{-1} (S_old - K_oo) K_oo^{-1} K_on.
   Use only for ablation and tests. This is not the main method.

7. old_likelihood_transfer_dense_for_test(...)
   Dense reference implementation:
       R_o = S_old^{-1} - K_oo^{-1}
       r_o = S_old^{-1} m_old
       L = K_on K_nn^{-1}
       Lambda_old = L.T @ R_o @ L
       h_old = L.T @ r_o
   Use only in small-size tests to check the structured implementation.

In src/joint_ssgp_kron/model.py implement:

Class JointSSGPKronHiPPOSVGP

Required methods:

1. __init__(...)
   Inputs:
       Ks, C, sigma2, beta_prior_mean, beta_prior_cov, jitter.
   Store fixed spatial factors:
       Ks = K_ZZ^(s)
       C = K_XZ^(s) (K_ZZ^(s))^{-1}
       G = C.T @ C.

2. initialize_state(Kt0, M_t, M_s, d)
   Initialize:
       B_temporal = zeros(M_t,M_t)
       H_info = zeros(M_s,M_t)
       M_u = zeros(M_s,M_t)
       beta posterior from prior.

3. update_block_ssgp_transfer(...)
   Inputs:
       y_vec, Phi, T_n, Kt_new, optional K_on_t, previous state, beta_drift Q_beta, inner_iters.
   Required:
       - If previous temporal basis differs, compute L_t = K_on_t @ inv(Kt_new).
         Important dimensions:
             K_on_t shape = (M_t_old, M_t_new)
             Kt_new shape = (M_t_new,M_t_new)
             L_t shape = (M_t_old,M_t_new)
       - Transfer:
             B_trans = L_t.T @ B_old @ L_t
             H_trans = H_old @ L_t
       - If fixed basis, L_t = identity and transfer is no-op.
       - For each inner iteration:
             a) compute GP mean contribution:
                    pred_gp_matrix = C @ M_u @ T_n.T
                    pred_gp_vec = vec(pred_gp_matrix, order="F")
             b) beta update:
                    S_beta_inv = S_beta_prior_inv + Phi.T @ Phi / sigma2
                    rhs_beta = S_beta_prior_inv @ beta_prior_mean
                               + Phi.T @ (y_vec - pred_gp_vec) / sigma2
                    beta_mean = solve(S_beta_inv, rhs_beta)
                    beta_cov = inv_or_cholesky_solve(S_beta_inv)
             c) residual:
                    residual_vec = y_vec - Phi @ beta_mean
                    residual_matrix = reshape(residual_vec, (N_s,N_t), order="F")
             d) update temporal likelihood stats:
                    B_new = B_trans + T_n.T @ T_n / sigma2
                    H_new = H_trans + C.T @ residual_matrix @ T_n / sigma2
             e) solve posterior mean M_u:
                    Solve Ks_inv M_u Kt_new_inv + G M_u B_new = H_new.
       - Save B_temporal = B_new, H_info = H_new, Kt_current=Kt_new, beta posterior, M_u.

4. update_block_projected_prior(...)
   Implement projected-prior approximation for ablation.
   It may materialize dense matrices for small/medium cases or use structured approximation if straightforward.
   Mark clearly as baseline/ablation.

5. predict(...)
   Inputs:
       phi_star, t_proj_star, c_proj_star, state.
   Here:
       a_star = t_proj_star \otimes c_proj_star.
   Mean:
       mean = phi_star.T @ beta_mean + c_proj_star.T @ M_u @ t_proj_star.
   Variance:
       Implement at least mean and optionally variance.
       For variance, use existing Sylvester quadratic-form solver if available:
           q_star = vec(Q_star), Q_star = outer(c_proj_star, t_proj_star)
           q^T Lambda^{-1} q = <Q_star, Z>.
       Include:
           sigma2 + phi_star.T beta_cov phi_star
           + GP prior/conditioning variance terms if available from existing baseline.
       If full GP variance components are not available from baseline, return a structured approximate variance and clearly document it.

6. materialize_dense_for_test(state)
   Small-size only:
       Lambda = kron(inv(Kt), inv(Ks)) + kron(B_temporal, G)
       h = vec(H_info)
       mean_dense = solve(Lambda, h)
       Used in tests only.

------------------------------------------------------------
Check 1: Dense vs Kronecker transfer operator L_on
------------------------------------------------------------

Goal:
    Verify:
        L_on = K_on K_nn^{-1}
             = L_t \otimes I_s.

Construct:
    K_on = K_on_t \otimes K_s
    K_nn = K_nn_t \otimes K_s

Compute:
    L_dense = K_on @ solve(K_nn, I)
    L_kron  = kron(L_t, I_s)

Expected:
    relative_fro_error(L_dense, L_kron) < 1e-8.

This check validates that L_on = L_on^(t) \otimes I_s is a consequence of:
    separable kernel + fixed spatial inducing locations + temporal-only basis change.

------------------------------------------------------------
Check 2: Dense vs Kronecker old-likelihood transfer
------------------------------------------------------------

Goal:
    Verify:
        L_on.T @ (B_old \otimes G) @ L_on
        =
        (L_t.T @ B_old @ L_t) \otimes G.

Construct:
    B_old SPD or PSD, shape (M_t_old,M_t_old)
    G = C.T @ C, shape (M_s,M_s)

Compute:
    Lambda_dense = L_dense.T @ kron(B_old,G) @ L_dense
    Lambda_kron  = kron(L_t.T @ B_old @ L_t, G)

Expected:
    relative_fro_error(Lambda_dense, Lambda_kron) < 1e-8.

This validates the Kronecker preservation of SSGP-style old-likelihood-ratio transfer.

------------------------------------------------------------
Check 4: Fixed-basis streaming update vs batch update
------------------------------------------------------------

Goal:
    In fixed inducing coordinates, sequential Gaussian updates should equal batch Gaussian posterior.

Construct:
    z = [beta; u] small dense state.
    Generate several blocks:
        y_j = H_j z_true + noise.
    Prior:
        z ~ N(m0,S0).

Streaming:
    Lambda_stream = S0^{-1}
    h_stream = S0^{-1} m0
    For each block:
        Lambda_stream += H_j.T @ H_j / sigma2
        h_stream += H_j.T @ y_j / sigma2
    m_stream = solve(Lambda_stream,h_stream)

Batch:
    H_all = stack H_j
    y_all = concat y_j
    Lambda_batch = S0^{-1} + H_all.T @ H_all / sigma2
    h_batch = S0^{-1}m0 + H_all.T @ y_all / sigma2
    m_batch = solve(Lambda_batch,h_batch)

Expected:
    relative error in mean < 1e-8
    relative error in precision < 1e-8.

This verifies the fixed-basis exact joint Gaussian baseline.
