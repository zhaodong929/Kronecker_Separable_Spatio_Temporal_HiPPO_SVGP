Theory requirements to implement:

1. Joint likelihood natural statistics

For a Gaussian block likelihood

y_n = Phi_n beta + A_n u_n + eps, eps ~ N(0, sigma2 I),

the new block contributes:

R_beta_beta,new = Phi_n^T Phi_n / sigma2
R_beta_u,new    = Phi_n^T A_n / sigma2
R_uu,new        = A_n^T A_n / sigma2
h_beta,new      = Phi_n^T y_n / sigma2
h_u,new         = A_n^T y_n / sigma2

In the separable spatio-temporal setting, R_uu,new should still be represented through the existing B_temporal / G structure whenever the assumptions hold. The cross block R_beta_u,new may be stored densely because beta dimension is small.

Do not compute residual = y - Phi beta_mean as the core joint update. That was acceptable for older factorized or plug-in logic, but the structured joint posterior must use joint natural statistics.

2. Old-likelihood-ratio transfer under changing temporal basis

The old likelihood ratio is over joint variables:

q_{n-1}(beta, u_o) / [p(beta) p(u_o)]

Under temporal-only basis change and fixed spatial inducing geometry:

L_on = L_t kron I_s.

The old u-u likelihood precision transfers as:

If R_uu,o = B_o kron G, then:

R_uu,o->n = (L_t^T B_o L_t) kron G.

The beta-u cross precision must also transfer:

Implement this without materializing L_on whenever possible:

3. Posterior recovery via Schur complement + Sylvester solves

Let the joint precision be

Lambda =
[ A_beta       B_beta_u
  B_beta_u^T   D_u      ]

where:
- A_beta = prior_beta_precision + R_beta_beta
- B_beta_u = R_beta_u
- D_u = Lambda_uu = K_u^{-1} + R_uu
- D_u is never explicitly inverted in the scalable path.

Define Schur-complement precision:

Lambda_beta_given_u =
A_beta - B_beta_u D_u^{-1} B_beta_u^T.

This symbol must be called Lambda_beta_given_u or Lambda_beta_conditional_precision in code/docs. Do NOT call it S_beta, because that confuses precision with covariance.

Implement posterior natural vector:

h = [h_beta; h_u].

Recover posterior mean by:
1. Solve D_u W = B_beta_u^T using Sylvester/Kronecker solver.
2. Solve D_u v_h = h_u using Sylvester/Kronecker solver.
3. Lambda_beta_given_u = A_beta - B_beta_u W.
4. m_beta = solve(Lambda_beta_given_u, h_beta - B_beta_u v_h).
5. m_u = v_h - W m_beta.

Recover useful covariance quantities:
- S_beta_beta = Lambda_beta_given_u^{-1}.
- Posterior cross covariance is not stored directly, but can be applied implicitly:
  S_beta_u = - Lambda_beta_given_u^{-1} B_beta_u D_u^{-1}.
- Do not claim R_beta_u is posterior covariance. R_beta_u / B_beta_u is a likelihood natural-precision cross block.

Add helper functions:
- solve_Du(rhs): use existing Sylvester-compatible solver.
- recover_posterior_mean_structured()
- recover_beta_covariance()
- apply_cross_covariance_beta_u(rhs) if useful.
- dense_joint_posterior_reference() for small tests.

4. Predictive mean and variance

For a test input, with linear feature phi_* and GP inducing projection a_*:

phi_*^T m_beta + a_*^T m_u.

The predictive variance must preserve beta-u covariance. Use the Schur-compatible formula:

Var(y_*) =
sigma2 + nu_* + a_*^T v_*
+ (phi_* - B_beta_u v_*)^T Lambda_beta_given_u^{-1}
  (phi_* - B_beta_u v_*),

where:
D_u v_* = a_*.

Here nu_* is the conditional GP residual variance term already used in the existing model. If the existing implementation has a different name, keep its convention but ensure the formula is mathematically equivalent.

Add a dense small-case test verifying that this variance exactly matches:

sigma2 + nu_* + [phi_*; a_*]^T Lambda^{-1} [phi_*; a_*].

Also add a test showing that the mean-field variance omits the cross term and differs from the structured joint variance in a constructed case with nonzero beta-u coupling.
